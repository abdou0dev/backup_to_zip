# Backup A folder into a zip file.
this tiny tool will create versioned zip backups (Inspired by the book 'Automating the boring stuff with python').

- I made it so a user can simply copy the script to the folder that needed to be backed up
- The script then will create a zip file in the parent directory and check the current backups that lives there for incrimination purposes
- Then a loop will walk over every folder to backup into the zip file.
